Menambahkan akun aparat

Buat user di Supabase Dashboard → Authentication → Users dengan alias default username@login.desa-komara.invalid, atau pakai alias penuh pilihanmu dan masukkan alias yang sama saat login. Setelah trigger membuat profil, aktifkan melalui SQL Editor. Panduan dan SQL aktivasi ada di supabase/SETUP.md. Jangan memakai service-role key di browser.

Akses Ditolak

Halaman ini hanya bisa diakses oleh akun dengan role "Super Admin". Hubungi Super Admin desa Anda kalau membutuhkan akun baru.
